# 开题报告 v5 第三阶段功效模拟（2026-11-09）

**原目标。** v4 的功效分析按"3 个模型 × 首轮相互独立"计算，不适用于 v5 的设计：只用 DeepSeek flash 一个模型，推理开、关两种模式分开分析，所有复核程序共用同一个首轮答案（分支设计）。本模拟用于确定 v5 的家族数、重复次数和 H1 的"可检验"门槛。

**方法。** 脚本 `power_v5_branching.py`，每种条件模拟 2,000 次，随机种子 20261109。分析方法与 v5 第 3.7.3 节一致：
- 以家族为单位。
- H1 用交换错误类型标签的精确或蒙特卡洛置换检验，双侧 α = .05；没有错误首轮的家族不参与。
- H3 和 H4 用单侧 95% t 上界。
- H2 用家族层面的 t 检验。

参数估计见 `estimate_params.py` 和 `params_from_dev.json`，有两类：

1. **从开发数据估计的：**
   - 困难家族中"会出错"的比例：H01–H12 里只有 H04，即 1/12。
   - H04 首轮在错误建议题上的错误率：13/64 ≈ 20%。其余困难家族约 2%（2/88）。
   - 同一题重复作答的错误相关：组内相关 0.07，相关很弱。
   - H04 上的修复率：自由复核 P1 8/13（62%），来源核验 P3 1/13（8%）。
   - 复核损坏正确首轮：1,110 次复核中为 0。
   - 缺证据时基线暂停的比例：94%。
   - 推理模式的首轮错误：证据在场的 132 个首轮中 0 个（分支运行 68 个，H04 推理探测 64 个）。
2. **无法估计、按情景假设的：**
   - P5 的修复率（P5 尚未运行）。
   - 来源适用类错误的修复率：开发中没有出现过这类自然错误。
   - 家族间修复率差异：logit 标准差 0.5。

修复情景分四种：
- **强交叉：**各针对性程序修复所针对错误的 62%、另一类的 8%，相当于 H04 上 P1 与 P3 的差距。
- **中等交叉：**50% 对 20%。
- **只在条款类有差异。**
- **无交叉：**用来检验假阳性率。

**结果。**

1. **H1 能否检验，主要取决于困难家族中有多少能让模型自然出错，而不是家族数或重复次数。**
   - v5 草稿的门槛（每类 ≥20 个错误首轮、来自 ≥5 个家族）过严。按 v5 草稿设计（每类 10 族、3 次重复），即使一半家族会出错，满足门槛的概率也只有 1.4%。
   - 重复作答之间相关很弱，所以在会出错的家族里，增加重复次数能成比例地增加错误数。但对已在天花板的家族，增加重复没有帮助。v5 草稿中"重复的错误往往同时出现、因此加重复没用"的说法与数据不符，已更正。
2. **门槛改为"每类至少 4 个家族各有 ≥1 个错误首轮"。**4 是精确置换检验能达到 p < .05 的最小家族数（4 + 4 个家族时，最小双侧 p = 2/70 ≈ .029）。在各种设计和情景下，这条门槛的无条件功效最高，假阳性率不超过 .06。
3. **推荐设计：**20 个标准家族加 30 个困难家族（每类 15 个）。困难层在推理关闭时做 6 次重复，其余情况 3 次。

   | 假设 | 情景 | 结果 |
   |---|---|---|
   | H1（推理关） | 出错家族比例为开发值 1/12 | 可检验 .87；强交叉功效 .76；中等交叉 .31；仅条款类 .28 |
   | H1（推理关） | 出错家族比例 1/4 | 强交叉 .94；中等 .57；仅条款类 .52 |
   | H1（推理关） | 出错家族比例 1/2 | 强交叉 1.00；中等 .81；仅条款类 .77 |
   | H1（推理关） | 无交叉 | 假阳性 .03–.06 |
   | H1（推理开） | 乐观假设：每个家族 3% 出错 | 可检验 .45；强交叉功效 .27 |
   | H1 作者预写草稿 | 修复率与自然错误相近 | 功效约 1.00 |
   | H1 作者预写草稿 | 所有程序修复 95% 的草稿错误（第二家模型的情形） | 功效 .03 |
   | H3（50 个家族） | 复核损坏 0%、1%、2%、3% 的正确首轮 | 1.00、1.00、1.00、.81 |
   | H4（20 个标准家族） | 接近开发数据（基线错误约 3%） | 支持 H4 的概率 .97 |
   | H4（20 个标准家族） | 某程序真实提升 5 个、10 个百分点 | 支持 H4 的概率 .89、.03 |
   | H2（50 个家族） | 无效应；P3 把未暂停的 60% 对 30% 转为暂停；90% 对 30% | .02；.36；.94 |

   如果每类增加到 20 个家族（共 60 个），在 1/4 家族会出错时，中等交叉的功效会从 .57 升到 .71。
4. **调用量与费用：**
   - 推荐设计共 30,600 次调用：推理关 18,000 次，推理开 12,600 次。其中 3,900 次是首轮，19,500 次是复核，7,200 次是草稿复核。
   - 按开发实测的空闲价，推理关约 75–85 元，推理开约 175–215 元。

**解释。**
- 第三阶段在任何情况下都能检验 H3 和 H4，即边界结论。
- 推理关闭时，只要交叉效应接近 H04 上观察到的规模，H1 有较高功效；效应只有一半大时功效不足，只能报告方向和置信区间。
- 推理开启时，H1 基本只能靠作者预写草稿检验。草稿如果太容易，这一路也会落空。
- H2 因基线已在 94% 的缺证据题上暂停，功效有限，应作为估计报告。
- 以上都是模拟结果，依赖上面列出的假设，尤其是 P5 和来源类错误的修复率。

**复现。** 在 `mechanism_study/` 下运行。

1. 先给三个还没有评分文件的结果目录评分：

   ```bash
   python harness/scorer.py results/flash_branch_dev --cases cases/dev
   python harness/scorer.py results/flash_think_branch_dev --cases cases/dev
   python harness/scorer.py results/flash_think_branch_hard --cases cases/dev_hard
   ```

2. 估计参数，再运行模拟：

   ```bash
   python analysis/power_v5/estimate_params.py results
   python analysis/power_v5/power_v5_branching.py --nsim 2000
   ```

   运行后得到 `power_v5_results.csv`（全部网格）和 `power_v5_recommended.csv`（推荐设计）。`show.py` 把全部网格打印成表格。
