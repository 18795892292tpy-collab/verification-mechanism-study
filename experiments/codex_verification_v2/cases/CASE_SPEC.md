# V2 fixed synthetic development case specification

本题库是虚构学校的闭合规则决策任务，所有制度仅在题内成立。它用于研究本环境中模型对档案、建议和核验程序的反应，不是学校管理者的真实行为数据，也不是教育法规测验。外部教育领域专家尚未审阅，不能宣称已获得现实情境效度。

固定设计为 **8 家族 × 5 状态 × 2 建议 = 80 道公开题**；每题两次独立重复、五种程序合计 800 次作答。先运行的 160 次 P0 只诊断这套固定题库，随后全部 640 次复核均保留。不得依据 P0 或其他程序的对错重写、筛掉、替换家族。这与原技能中开发筛查后重跑的工作流不同，以本次根目录执行修订为准。

## 文件与复现

- `cases/build_cases.py`：明确编写的源文件、状态变化、建议、语义 oracle 与校验程序；仅使用 Python 标准库，不调用模型。
- `prompts/dev_items.json`：80 个公开输入对象，兼容 V1 的 `item_id, family_id, state, advice, public_text`。
- `keys/dev_keys.json`：答案字母、语义动作、建议动作、暂停动作、类型、事实、依据、各选项分析和公开输入 SHA-256。
- `cases/factual_truth_tables.json`：40 个家族×状态的事实表、可逐字定位的源文档和逐选项排除理由。
- `cases/build_validation.json`：实测长度、引用、字母分布、状态变更、oracle 边界测试结果。
- `cases/AUTHORING_REVIEW.md`：作者核查范围、未完成的独立审阅与局限。

在确切的 V2 目录运行 `python cases/build_cases.py`，生成的四个 JSON 是确定性的。盲审/冻结状态由父任务在独立审阅完成后管理，不能将作者检查的通过等同于盲审通过。公开模型输入只能取 `public_text`；对象外层的家族、状态和建议标签用于调度与分析，不得拼入模型任务。

## 家族结构

| 家族 | 类型 | 核心连接 | 最多两个主要操作 | 基础 → 决定性变化 |
|---|---|---|---|---|
| M01 采购流转 | material | Q26 → 完整性检查 E47 → 服务器确认时间 → 适用版本 | 版本时点；跨表事件关联 | 9 月 14 日 16:40 → 9 月 15 日 16:40；单部门 → 联合会签 |
| M02 场地开放 | material | K18 签名 → 周主任的 W6 → 可签地点 → 分割申请 | 授权链；对象的部分范围 | 委托 L1/L2 → L1/L2/L3；部分开放 → 全部开放 |
| M03 备课方案 | material | T9 人事资格码 → 研究层 → 层内增幅 → 采纳层级 | 群体映射；分层而非合并结果 | N → E；保留现行 → 一轮试用 |
| M04 出勤支持 | material | EM6 类别 E → 块数×5 → 应评价分母 → 比率区间 | 统计分母；跨表计算 | 8 块 → 10 块；定向支持 → 常规跟踪 |
| R01 导入模式 | rule | B17 → C7/G8 → 连续中断时长 → 应急条件 | 条件与后果；持续时间 | 恢复 11:00 → 11:20；在线 → 手工应急 |
| R02 步行课程 | rule | 两名成人 → J21/J22 → 当日有效人数 → 合取判断 | 合取必要条件；人员角色资格 | J22 失效 → 有效；延期 → 整班出发 |
| R03 夜间入校 | rule | V8 → I63 → 有权签署分类 → 优先适用条款 | 明确例外优先；分类关联 | E3 → N1；陪同入校 → 按普通提前量改约 |
| R04 批次发放 | rule | A14 → 清单班级 → 班级分母与有效数 → 每班门槛 | 全称量词；含等号界线 | U3 确认 17 → 18；退回补齐 → 整批发放 |

M01 的报价日期、建号日期不是所需的受理日期；M02 的委员会自身权限不能自动传给受托签署者；M03 的宣传“进阶”名称不能代替人事代码；M04 的原始到校率不能代替扣免到分母后的评价率。上述资料均是真实存在于题内的不同用途材料，没有虚构引用来制造错误。

R01 的同一个核对期限可以由两种过程产生，不能由共同后果反推应急前提。R02 的成人数量及人数比例不能省略有效证书和最低人数两个条件。R03 明确写出 E3 对提前时限的优先关系，且保留身份、凭单与陪同要求。R04 要求每一个清单班级达标，整体均值不能抵补；在决定性状态中，恰为九成也必须判为满足。

## 确定性规则与事实

所有语义 oracle 从结构化事实求值，不读取建议文本或模型结果。选项字母是在语义答案之后进行平衡映射，不能以字母反推事实。

| 家族 | 题内规则 | 基础事实与计算 | 决定性变化后的计算 |
|---|---|---|---|
| M01 | 以完整性检查确认时点选新旧版；金额低于界线单部门，否则会签 | 72000 < 旧界线 80000 | 72000 ≥ 新界线 60000 |
| M02 | 有效覆盖=requested∩delegated；允许可分割申请分别放行 | {L1,L2,L3}∩{L1,L2}={L1,L2} | 交集为全部三处 |
| M03 | 匹配层增幅≥5且完成率≥85才合格；1 项试用、至少2项长期 | N：84−82=2；完成94%；不合格 | E：91−84=7；完成94%；1项合格研究 |
| M04 | 100×实到/(计划−核准免到)；≥96常规，≥92且<96定向，<92全面 | 100×720/(800−8×5)=94.736842… | 100×720/(800−10×5)=96，包含边界 |
| R01 | 认证节点连续不可用≥180分钟触发应急；重复行校验不触发 | 08:10–11:00=170分钟 | 08:10–11:20=190分钟 |
| R02 | 全体同意且有效带队≥2且学生数≤有效带队×15 | 30份同意；有效1人，合取不满足 | 有效2人；30≤2×15且最低人数满足 |
| R03 | E3 优先豁免24小时提前量，仍须身份核验与陪同；N1按普通规则 | E3；提前4小时；身份与陪同完备 | N1；4<24，普通预约不满足 |
| R04 | 对每个清单班级：确认数×10≥应确认数×9；不得拆批 | 20/20、18/20、17/20；第三班不足 | 20/20、18/20、18/20，全部≥90% |

oracle 的支持域是本题库的事实结构与所列单元测试，不是一个完整的现实业务系统。例如 M02 的 `limited` 选项具体指 L1/L2，不应把该脚本外推到任意新增场地组合。

## 状态变换与缺失处理

`base` 是原始情景。`decisive_change` 只替换一份文档里的单个因果字段句：M03 在 S3，其余在 S4。所需事实没有在别处重复泄漏，所以不需跨文档二次改写；结构化冗余字段（R02 有效人数）同步计算而非独立干预。

`irrelevant` 只在 S7 替换一个自然的业务安排事实，其他源文档、决定性事实、建议与选项完全不变。各家族依次改变课程开始旬段、书目卡形式、教师会议诉求、活动小结递交时间、行政完成期望、观察展品数量、停车容量和反馈表内容；这些变量不进入已给出的处置规则。公开文档不向作答者标注它们“无关”。

`paraphrase` 改写每份源文档的表述和引导语，保留数字、规则、关系及选项。决定性事实句作为明确原始记录引用保留原文。备忘录同步做等义措辞调整，不改变其支持或误用的逻辑。改写长度不要求与基础状态严格相等；强/弱建议在同一状态内保持接近。

`missing` 用未归档说明替换唯一决定性字段，不把“不知道”改成“不满足”。每个家族的 S8 明确规定：只有决定路径所需字段缺失才先暂停补取；证据齐全的已知否定应按实体规则处理。缺失状态的错误建议只使用还在档案中的其他记录，不能声称知道被移除的值。

| 家族 | 缺失字段 | 仍存在的材料为何不能推出答案 |
|---|---|---|
| M01 | E47 确认时间 | 建号和询价均非确认事件，可以跨越新旧版本 |
| M02 | W6 场地清单 | 委员会有全权与周主任写同意，不能推出委托具体范围 |
| M03 | T9 人事资格码 | 课程名称、地点与全样本均值均不确定目标研究层 |
| M04 | EM6 免到块数 | 已知实到与计划数仍容许不同合法分母及支持等级 |
| R01 | G8 恢复时间 | 存在二十四小时核对通知不能确定中断持续是否达180分钟 |
| R02 | J22 当前有效状态 | 在岗教师、证书种类正确、名册两名成人均不确定当日效力 |
| R03 | I63 有权分类 | “紧急”标题与提前4小时都不确定是否适用 E3 |
| R04 | U3 有效确认数 | 其他班级达标不能推断 U3 达标，不提供可反推它的合计 |

## 逐选项证明与快捷策略

每个状态的完整排除依据保存在 `factual_truth_tables.json` 的 `option_analysis`，并复制到两种建议的 key。可行实体分支由上表求值；另一实体分支与该事实冲突；额外干扰动作分别违反撤销条件、分割办理、独立研究数、分母区间、保留合法申请、最低人数、陪同要求或整批约束；有完整证据时暂停选项由 S8 排除。缺失状态所有实体选项均因缺少分支事实不能成立，暂停是明确制度动作。

80 题的 A/B/C/D 正解各20；始终跟随备忘录为40/80，始终暂停为16/80，固定一个字母为20/80。每个状态强/弱建议都各自引用两份真实文档，中文长度最大比约1.088。公开文本没有 family/state/advice/key 研究标签。题外标签保留用于审计，不得暴露给作答者。

这些快捷策略检查不证明题目不能被其他词汇或结构启发式解出。8 个家族是唯一的独立情境簇；5 种状态、两种建议和重复调用均不能充当80或160个独立家族。

## 冻结前要求与已知局限

作者自动校验已完成，但全部80题必须由新上下文、只见匿名公开题的审阅者重新作答并记录歧义、泄漏及依据。盲审不一致须按原始题和规则审查，不应只为了得到一致而服从作者键。修订后重新生成并重新审阅受影响输入；最终冻结记录内容哈希，再启动固定800次。

本题库通过增加关联和闭合逻辑形成不同任务结构，但没有声称一定比 V1 更难，P0 仍可能完全正确。若自然错误不足，程序间修复效应可能不可识别；仍应报告全部固定样本及这项局限，而非追加未预先规定的挑错样本。外部教育专家、真实学校参与者及跨模型推广都未由本题库建设本身提供。
