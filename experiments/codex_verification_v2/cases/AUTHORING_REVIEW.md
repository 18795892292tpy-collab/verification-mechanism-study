## 构建与适用规则

本次参考仓库的 `verification-case-builder/SKILL.md`，采用家族聚类、五状态、双建议、明确暂停条件、真实题内引文、最小决定性变化及冻结前审阅要求。本次执行修订明确固定80题、每题两重复五程序共800次，因此不执行技能中“发现基础全对后继续调整题目”的结果筛查循环。160次P0作为固定样本诊断保留，之后不因结果更换题目。

没有调用模型来生成作答或假装完成实验；题目、事实、规则与 oracle 是本代理编写，确定性检查由本地 Python 执行。作者既写源文档也写 oracle，不应将同源代码一致性称为独立证实。独立匿名审阅及冻结尚由父任务负责；本文件不会预先为其签署通过。
