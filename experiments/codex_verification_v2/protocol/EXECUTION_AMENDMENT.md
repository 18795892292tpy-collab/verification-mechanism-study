# 800 次固定开发矩阵：执行前修订

用户原文授权：“收尾准备题库并且启动800次 做完后提交到GITHUB”。本修订在 v2 任何被试模型作答前制定，优先于 approved_plan.md 中额外筛查、选题和追加预算的旧建议。

- 固定 8 个新家族（4 材料适用性、4 规则条件），每家族 5 状态 × 2 建议方向，共 80 题。每题 2 次独立首轮重复，每组含 P0/P1/P3/P7/P8，共 800 个计划任务。
- 先执行全部 160 个 P0，仅描述难度与天花板，不按其结果选择、删改、替换家族；随后执行同一 160 个首轮对应的 640 个复核。即使出现天花板也完成固定矩阵。
- 不另外运行 160 次筛查或模型校准，不实施原提案的 960/1120 调用预算。离线模拟测试和内部匿名题库审查不计为实验模型作答。
- 复核共享同一组 P0 原文及哈希，不同程序使用隔离的新临时上下文。错误答案、合法 final 的解析失败不重新抽样。只有没有 final 的技术失败可有限重试，实际调用数与 800 计划任务分开报告。认证/配额问题自动暂停，保留可恢复记录。
- 只用同主机 Codex CLI 显式请求 gpt-6-astra / ultra，不运行 DeepSeek，不合并 v1 或历史 DeepSeek 结果。
- 题目是作者构造的虚构学校规则，参考答案来自作答前写定的语义规则、真值表和排除证明；不是对模型回答倒推的答案。匿名内部审查属于同模型家族检查，不是独立教育行政专家验证。
- 当前没有外部教育行政专家参与。本批的评价类型为 simulation_only，开发性、描述性；不能作为真实校长/教师行为或现实教育政策有效性的证据。
- 模型任务开始后，题目、答案、提示、计划与评分代码冻结。发现问题必须原样报告，不事后改答案使结果变好。独立审计复算可另存，不改原始记录。
- 最终提交原仓库的研究材料、全部实验记录、统计、审计与图；保留历史审查记录并说明偏离。GitHub Fork 按用户先前选择保留。
