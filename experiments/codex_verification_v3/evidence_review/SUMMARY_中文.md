# V2 既有回答依据质量审查（V3 事后探索）

审核对象是 V2 的 16 组题目及重复，每组五程序，共 80 条已保存回答；覆盖8个家族、每程序16条。抽样是事先固定的分层便利抽样，非随机概率样本。评审前冻结题目包和量表；本分析发生在 V2 实验之后，不改变原 V2 的行动正确率，也不评估全部800条。没有重新调用被试模型。

两名内部评审均判断：80/80 条未发现明确事实矛盾，80/80 条可见决定依据充分，80/80 条引用支持可见核心理由。三项逐条一致均为80/80；两位评审在每项都只使用了一个类别，Cohen κ 分母为零，记 NA，不能解释成经过机会校正的完美可靠性。不存在标签分歧。

复核脚本核验了冻结包、原V2冻结哈希及80条源记录哈希、公开档案和回答的逐字绑定、抽样规则、评级ID和枚举、答案引文为原文子串、所列来源编号存在，以及评级时间晚于审核冻结。自动检查只核对这些形式条件，不能单独证明每条语义判定正确。

共有 1 个证据说明中的引号片段不连续出现在原文；原评审 A 的 C05A1 使用省略号（“U3…计数页未归档”），应理解为概述，不是逐字引文，原记录保留不改。

审查者为同模型家族内部代理，后端具体模型身份无法独立核验；并非独立教育领域专家。短理由有长度限制，审核仅针对可见文字及引用，不证明模型隐藏推理、回答生成过程或真实学校决策。16组是家族聚类样本，本结果不能推断全部800条的质量比例，也不能证明复核程序更好或等价。

完整统计、三项定义、样本分布、输入SHA-256和逐条分歧见 [SUMMARY.json](SUMMARY.json)；两位原始评分保留在 ratings_A.json 和 ratings_B.json。可在原主机运行 `python evidence_review/summarize_ratings.py` 复算（会覆盖本汇总文件，不会修改冻结输入和原始评分）。
